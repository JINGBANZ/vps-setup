    03 / Understand what runs

    There is no fixed “run every module” sequence on macOS. The entrypoint uses local helpers, then runs only selected work.

    1. Homebrew, if needed. Install it once only when a selected missing formula needs it.
    2. Formula tools. One install call for each missing selected Tailscale, Mosh, tmux, Git or GitHub CLI.
    3. Native tools. 60-node-bun.sh runs separately per selected runtime; 70-agents.sh separately per selected agent. Each call enables only that tool.
    4. Configuration. 80-tmux.sh renders the shortcut; shell integration adds managed initialization. Only differing content is written.

    Inventory renders a temporary shortcut for comparison too, without changing your configuration. Linux security, PostgreSQL, runner and disk-monitoring modules do not run.

    04 / Read the result

    Installed Already present Configured Configuration current Skipped Failed Manual repair needed

    Every rerun redetects tools before using saved choices. A saved selection cannot reinstall a working tool. Failed selected installations cause a nonzero exit; repair the issue and rerun.

    Matching files stay untouched. Changed managed files get a one-time original backup; custom shell lines remain. Symlinked files needing changes require manual integration.

    A successful local inventory is not proof of working remote access. Detected broken tools stay locked and can still appear in a successful no-op inventory.

    05 / Keep these manual

    System and account settings

    Remote Login, optional Screen Sharing, allowed users, power settings and sign-in remain outside the menu. Setup does not run connection probes or inspect power settings.

    For a new Homebrew Tailscale installation only, follow the official service instructions when ready: sudo brew services start tailscale, then sudo tailscale up. Keep an existing working Tailscale variant.

    Sessions and restarts

    t my-task creates or reattaches a session. Ctrl-b, then d detaches; Ctrl-b, then s opens the session picker.

    tmux keeps processes running through terminal disconnects while the server stays alive. It does not preserve live sessions through a Mac reboot. FileVault unlock and restart recovery are separate operational tasks.
